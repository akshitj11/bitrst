# 2026-W34

P2P, genesis replay, mempool, and disk storage landed this week. CLI chains stay in RAM.

`PeerManager` already had handshake, inventory fanout, and bounded shutdown. This week it shares one `ChainHandle` and one `MempoolHandle` across peers. Relay handles `inv`, `getdata`, `tx`, and `block`. `getdata` for a mempool tx revalidates against the current UTXO set before the bytes go out.

Mainnet genesis still round-trips: deserialize, hash `000000000019d668…`, Merkle match, exact reserialize, `Chain::new_genesis` at time `1231006505`. Criterion benches compile in CI. Timings stay local.

Mempool admission uses the active UTXO set plus in-pool spends. Coinbase, duplicate txid, duplicate inputs, missing UTXOs, and failed P2PKH all reject. Caps are 5,000 txs and 300 MB serialized. Eviction is lowest fee rate, then oldest admission. Evicting a parent removes descendants in the same step so `getdata` cannot serve an orphaned child.

Reorgs drop confirmed txs, then restore disconnected spends that still validate. The event journal and disconnect journal are both 256 entries. A lagging cursor replays if the window still holds the sequence. Past that window, resync returns `MempoolResyncError` instead of inventing history.

`FileBlockStore` writes one lowercase-hex file per hash. Same-directory `.tmp`, `fsync`, `rename`. Open deletes leftover temps and names that are not 64 hex chars.

What actually broke while wiring this:

MTP rejected `bitrst mine --network-time 1231006505` because the next block must be strictly later than genesis time. Use `1231007105` or omit `--time`.

A wallet `take_events` drain used to wipe the log before a peer cursor collected it. The journal is now multi-consumer. Drain advances a wallet high-water mark. Cursors replay. Falling off the window is an error.

Serving a mempool tx after reorg without rechecking it returned a spend that no longer existed. `serve_transaction` revalidates and drops stale entries.

CLI persistent chain, addrman, and headers-first sync are still open. Wallet balance is genesis-only until the CLI loads a stored chain.
